プライバシーポリシー

制定日：2026年10月12日

本プライバシーポリシー（以下「本ポリシー」といいます）は、当方が提供する「納品書 PDF 生成ツール」 （https://www.reveriel.com/nohinsho-pdf/ 以下「本サービス」といいます）における、 利用者の個人情報および利用者データの取扱い方針を定めるものです。

1. 本サービスの基本的な仕組み

本サービスは、納品書の内容をブラウザ上で作成し、PDF として保存・印刷するためのツールです。 入力フォームに入力された内容（自社名・住所・電話番号・メールアドレス、納品先の情報、明細、金額、備考など）は、 当方のサーバーへ送信されません。 これらの情報はすべて利用者の端末のブラウザ内だけで処理され、生成される PDF も利用者の端末内で作成されます。 ページを閉じると入力内容は破棄され、当方が取得・保存することはありません。

2. 取得する情報

当方は、本サービスの提供にあたり、次の情報を取得することがあります。

  • お問い合わせ・フィードバック等で利用者から任意にご提供いただいた内容（お名前、連絡先、ご意見等）
  • アクセス日時、閲覧ページ、参照元、ブラウザや端末の種類、IP アドレス等の技術的な情報（アクセス解析によるもの）

前項のとおり、納品書作成フォームに入力された内容そのものは、当方のサーバーへは送信されず、当方はこれを取得しません。

3. 利用目的

取得した情報は、次の目的で利用します。

  1. 本サービスの提供、維持、改善および不具合の修正のため
  2. 利用状況の把握および統計的な分析（個人を特定しない形での利用を含みます）
  3. お問い合わせ・フィードバックへの対応のため
  4. 本サービスに関する重要なお知らせの連絡のため
  5. 法令に基づく対応のため

4. Cookie 等および外部サービスの利用

本サービスは、利用状況を把握しサービス改善に役立てるため、アクセス解析ツール （Cloudflare Web Analytics）を利用しています。同サービスは Cookie を使用せず、個人を特定する情報を収集しない設計とされていますが、 IP アドレス等の技術的な情報が同サービスの提供者に送信される場合があります。

本サービスの表示には、フォント配信サービス「Google Fonts」を利用しています。 同サービスの利用に伴い、利用者の IP アドレス等の技術情報が同サービスの提供者に送信される場合があります。 各外部サービスの詳細な取扱いについては、それぞれのプライバシーポリシーをご確認ください。

5. 第三者提供

当方は、次の場合を除き、取得した個人情報を第三者に提供しません。

  1. 利用者の同意がある場合
  2. 法令に基づく場合
  3. 人の生命、身体または財産の保護のために必要があり、本人の同意を得ることが困難な場合
  4. 本サービスの運営に必要な範囲で、業務委託先に取扱いを委託する場合（この場合、当方は委託先を適切に監督します）

6. 安全管理措置

当方は、取得した個人情報の漏えい、滅失または毀損の防止その他の安全管理のために、必要かつ適切な措置を講じるよう努めます。 本サービスは HTTPS による通信の暗号化に対応しています。 また、前述のとおり納品書の入力内容はサーバーへ送信されないため、入力内容が当方の管理下で漏えいする余地はありません。

7. 開示・訂正・削除等の請求

利用者は、当方が保有するご自身の個人情報について、開示、訂正、追加または削除を求めることができます。 ご希望の場合は、下記のお問い合わせ窓口までご連絡ください。 ご本人であることを確認のうえ、法令に従い、合理的な期間内に対応します。

8. 未成年者の利用

本サービスは、事業者の方が業務として利用することを想定しています。 未成年の方が利用する場合は、保護者の同意を得たうえでご利用ください。

9. 本ポリシーの変更

当方は、法令の変更やサービス内容の変更等に応じて、本ポリシーを変更することがあります。 変更後の本ポリシーは、本ページ上に掲示した時点から効力を生ずるものとします。 重要な変更を行う場合は、本サービス上で分かりやすい方法によりお知らせします。

10. お問い合わせ窓口

本ポリシーに関するお問い合わせ、および個人情報の取扱いに関するご請求は、次の窓口までご連絡ください。 メールアドレスでのご連絡を希望される場合は、下記フォームよりその旨をお知らせください。請求があった場合には、遅滞なく開示します。

  • 運営者：GUO XING（詳しくは運営者情報をご確認ください）
  • お問い合わせ：お問い合わせ・フィードバックフォーム
